Comment ça marche ?

  1. Copiez un hash observé sur un rapport papier ou un export PV.
  2. Collez-le dans le champ ci-dessus (8 caractères minimum suffisent).
  3. Le serveur localise le maillon, recalcule son hash à partir de son contenu, et compare.
  4. Si les deux hashs matchent, la ligne d'audit n'a jamais été altérée en base.
